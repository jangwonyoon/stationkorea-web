# GEO 측정 기록

절차·질문·판정 기준은 [geo-test.md](./geo-test.md).

## 일정

v1 최초 공개일: **2026-10-29** — 인스타 프로필 링크 `stationkorea.com/ig` 설정.

디자인 개편의 production 배포일을 v2 실험의 새 D+0으로 삼는다. v1 기준선은 **2026-10-29부터 v2 배포 직전까지**이며, `tpl` 속성이 없는 기존 이벤트를 v1, `tpl: "v2"`인 이벤트를 v2로 구분한다.

| 시점 | 날짜 | 할 일 |
|---|---|---|
| v2 D+0 | production 배포일 미정 | 실제 배포일 기록, Umami Events에서 4개 커스텀 이벤트의 `tpl: "v2"` 확인 |
| v2 D+14 | v2 배포일 확정 뒤 산정 | 2주 실험 판정. v1 기준선과 v2 지표를 분리해 보고 |

아래는 v1 최초 공개 당시의 일정이다. v2 D+0·D+14는 실제 production 배포 뒤 위 표에 기록하며, 아래 D+14는 재시작한 실험의 판정일로 사용하지 않는다.

| 시점 | 날짜 | 할 일 |
|---|---|---|
| D+0 | 2026-10-29 (목) | 공개. Google·Bing·네이버 등록, sitemap 제출, 색인 요청 완료 |
| 매주 월요일 | 11-02부터 | 아래 "주간" 표 한 줄 |
| D+14 | 2026-11-12 (목) | 2주 실험 판정(설계 문서 성공 기준) + GEO 패널 1회차 |
