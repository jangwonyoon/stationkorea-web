# 2차 디자인 원본 대조표

2026-11-03 기준. 이 문서는 [v1 기준](../v1/README.md), [현재 승인 결정](../station-korea/decision.md), 수령한 2차 HTML의 **27개 보드**, `origin/develop`의 화면 구현을 대조한다. 원본의 모든 보드가 승인된 시안은 아니다. 사용자 결정과 실제 발행 자료가 원본의 옛 문안·예시보다 우선한다.

## 자료와 판정 방식

- 수령 원본: `매일 그 길 · STATION KOREA — 디자인 원본.html` (사용자 제공, SHA-256 `fab1c523c27994a1afc4a09bc3115b5ccedb7f4325e08a14591440814f82b9d0`). 단일 5.38 MB 파일 안에 27개 HTML 보드와 자산이 압축돼 있다. 공개 저장소에 원본 전체를 복제하지 않는다.
- 별도 홈·탐색 프로토타입: `STATION KOREA 프로토타입.html` (SHA-256 `b2af60dbc48bb9dd29b2d2ea28251aacfce00a73795a606220b7e039038393a3`). 브랜드/홈/기사 탐색은 이 프로토타입과 이후 승인 결정이 옛 홈 보드보다 우선한다.
- 보드 번호는 원본 캔버스의 **0부터 시작하는 순서**다. 0~6은 대응·브랜드 결정 자료, 7~22는 디자인 화면, 23~26은 확장 제안이다. 각 행의 “현행/조치”는 `origin/develop` 코드와 승인 결정에 대한 대조이며, 실제 브라우저 픽셀 비교·인앱 실기기 시험을 완료했다는 뜻은 아니다.
- 분류: **채택** = 현행 원칙과 일치, **변경** = 승인된 방향이지만 구현 차이가 있음, **대체** = 뒤의 사용자 결정/시안이 우선, **보류** = 자료·결정 부족, **비채택** = 폐기한 비교안. `[값]`·`{{값}}`·`#` 링크·임시 문장·예시 그래프는 발행 데이터가 아니다.

## 실제 후속 판단

1. **토큰과 기사 첫 화면 시각 검증**: 2차 따뜻한 색·32/56 제목·여백을 현재 라이트/다크·390/768/1280 기사 화면과 같은 조건에서 비교한다. 읽기·대비·첫 화면 가시성이 좋아지는 값만 별도 화면 PR로 반영한다. #43 문서 PR에서 `globals.css`를 수정하지 않는다.
2. **인앱 첫 화면**: 360×800과 390×844에서 실제 브라우저/인앱 상하 UI를 고려해 역명판, H1, 답, 이미지 시작 위치·가로 넘침을 측정한다. 보드 14의 수치는 설계 가정으로만 사용한다.
3. **노선 허브 정렬**: 역 번호순 표현을 원하면 공식 역 코드·운행/분기 구조·한 역에 여러 기사인 경우의 정렬 기준부터 확인한다. 현행 최신순은 정확히 표시되고 있으므로 검증 전 임의 변경하지 않는다. 원본의 `[역 번호]`와 `[00]km`는 발행 금지다.
