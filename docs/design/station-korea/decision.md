## 확정된 역할과 문안

웹사이트는 **STATION KOREA**, 인스타그램·영상 채널은 **매일 그 길**이다. 원본의 A안(STATION KOREA 주 표기)을 채택하며 두 이름을 동등하게 병기하거나 ×로 결합하지 않는다. 추가 A/B 비교는 만들지 않는다.

- 첫 문장: “역에서 시작해, 길과 동네와 도시를 읽습니다.”
- 보조 문장: “교통과 공간의 구조, 그 주변의 생활과 변화를 이야기하는 웹매거진입니다.”
- 영상 연결: “영상으로 만나는 매일 그 길 ↗”
- 헤더: STATION KOREA / 기사 / 노선 / 소개 / 테마 전환

역과 교통에서 출발해 길·동네·도시의 구조와 생활·변화를 다룬다. 서울 지하철은 현재의 출발 콘텐츠이며 매거진 전체의 제한이 아니다. 전국·세계 보도나 발행 일정을 약속하지 않는다. 기사는 릴스 없이도 읽히며 영상과 별도로 근거·문장·구성을 검토한다.

## 탐색과 기존 주소

- 처음 보는 글: 홈 대표/최근 → `/articles/` 또는 `/section/<section>/` → 기존 기사.
- 같은 장소·노선의 글: 카드 장소/노선 표시 → 실제 노선 허브 → 관련 기사.
- 출처·정정 원칙: 푸터 → `/about/#sources-policy`, `/about/#corrections`.
- `/station/`, `/article/`, `/line/`, `/about/`의 기존 경로와 홈 `#all`, `#new-articles`, `#lines`를 보존한다.
- 기사가 없는 섹션은 준비 중이며 빈 색인 페이지를 생성하지 않는다.

## 공유 자산과 보류

기존 OG 세 장을 직접 확인했다. 건대입구 OG에는 옛 채널명이 포함돼 있고 나머지는 단면 이미지였다. 같은 파일 경로에 현재 기사 제목·노선 표시와 승인된 STATION KOREA 워드마크를 사용한 1200×630 텍스트 공유 이미지를 제공한다. 새 심벌·가상 장소 이미지는 만들지 않는다. 생성에는 정적 출력의 제목/노선과 기존 셀프 호스팅 서체·토큰을 사용한다. `pnpm build` 후 `out/` 로컬 서버를 띄워 `node scripts/generate-brand-og.mjs http://localhost:<port>`로 재현하고 다시 빌드한다. 렌더 스크립트의 고정 캔버스 스타일은 이미지 생성 전용이며 사이트 런타임 스타일 예외를 추가하지 않는다.

favicon.ico는 기존 검정 바탕/흰 삼각형 기본 아이콘이다. 연결 심벌/모노그램 최종안이 없으므로 이번 변경에서는 유지한다. 최종 브랜드 심벌 적용 완료로 해석하지 않는다.

## 기사 상세 누락 정정 (#146)

2026-11-01 사용자가 지정한 `역 기사 사당 · 1280-html/Article-1280.dc.html`을 다시 확인했다. #119에서 기존 역명판 배치를 보존한 것은 승인 디자인의 누락이었다. #119를 다시 열고 #146을 실제 하위 이슈로 연결했다. 이전 홈·목록 검증만으로 기사 상세 시안까지 완료했다고 판단하지 않는다.

실제 1280 렌더 기준 역명판은 x40/y109, 1200×380이며 중앙 흰 판은 380×196이다. 본문과 레일은 그 아래 48px부터 시작한다. 이 배치의 공통 문법을 사당뿐 아니라 전체 발행 역 기사에 적용한다. 기준 노선은 가로, 확인된 환승 노선은 세로 띠와 중앙 배지로 표현한다. 실제 지리나 배선도 복원이 아니다.

기존 `sign.prev/next`와 공식 환승 안내의 방면 문자열만 재사용한다. 인접역과 종착 방면을 같은 정보로 단정하지 않고, 환승 자료에서 가져온 라벨에는 “방면”을 유지한다. 원본의 상하 라벨을 모든 역에 복사하지 않는다. 3개 이상 노선, 긴 이름, 성수 지선도 같은 중앙 판 문법 안에서 실제 데이터에 맞게 표현한다. 숫자 카드·이미지·영상이 없는 독립 기사에는 임의로 만들어 넣지 않는다.

원본 1280 HTML은 390에서 중앙 판과 라벨이 잘린다. 모바일은 유동 폭 중앙 판과 별도 방면 행을 사용하며,데스크톱 픽셀 배치를 그대로 축소하지 않는다. 현재 STATION KOREA 제호·색 토큰·서체·하차 안내 위치·출처 체계가 원본의 옛 문구와 콘텐츠보다 우선한다.
