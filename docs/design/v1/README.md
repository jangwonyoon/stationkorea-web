## 원칙 (요약)

- 눈에 띄는 장치는 기사 첫 화면 역명판 하나. 나머지는 먹 글자, 콘크리트 바탕, 1px 선.
- 서체가 화자를 구분: Hahmlet = 질문·에디터의 말, IBM Plex Sans KR = 숫자·출처·공식 정보.
- 노선색은 면에만(띠, 원형 번호, 칸 강조). 글자는 항상 먹색. 노선색 외의 색은 출구 번호 노랑 하나.
- 숫자는 근거와 한 몸: 큰 숫자 바로 아래 기준일, 오른쪽 위 각주 번호.
- 3D 단면 렌더가 주인공: 4:5, 글자를 얹지 않음, 캡션은 이미지 아래 왼쪽.
- 움직임은 한 번, 한 곳: 역명판 띠 그리기 900ms. reduce면 처음부터 그려진 상태.
- 환승역 두 색 규칙: 기준 노선(역명판 앞뒤 역이 속한 노선)이 가로 띠와 강조색, 갈아타는 노선은 역 자리에서 세로로 가로지르는 짧은 띠와 원형 번호로만. 두 색을 반씩 나누거나 섞지 않음.
- UX: 질문과 답이 첫 화면 660px 안(헤더 48 + 역명판 96 + 제목 3줄 112 + 답 9~10줄 270 + 바이라인 44 ≈ 610px). 하단 고정 바 없음. 터치 44×44 이상. 출처는 접지 않고 위계만 낮춤. 헤더는 질문·노선·소개 세 단어 노출, 아래로 스크롤하면 숨고 위로 스크롤하면 돌아옴. "다음 기사"가 아니라 "그럼 ○○는 왜?".

## v1 이후 확정된 변경 (2026-10-30, v1 시안보다 우선)

- 섹션 4개: #갈아타다(역·환승 구조) · #걷다(출구별 동네·보행·생활, 먹거리 포함) · #보다(랜드마크·공간) · #바뀌다(도시 변화·새 노선·숫자 소식). v1의 #먹다는 #걷다로.
- 제호 "매일 그 길". 홈 H1 "매일 지나는 그 역, 왜 이렇게 생겼을까". 기사 번호 "역 해부 01·02·03".
- 단면 이미지 캡션 끝 "AI 시각화 참고 이미지.", 방문 통계 문구 "쿠키 없이 익명 방문 통계(Umami)를 셉니다. 개인정보는 수집하지 않습니다.", 문의 stationkorea.official@gmail.com.
- 정정 기록 4칸(날짜 / 이전 값 / 새 값 / 사유).
- 하차 칸 = "타고 있는 열차 방면 → 갈아탈 방면 → 칸 + 소요 시간" 행 구조(사당 원자료 6행은 [PR #22](https://github.com/jangwonyoon/stationkorea-web/pull/22) 참고).
- 매거진 리듬: 실제 렌더 사용, 홈은 렌더가 보이는 표지 + 썸네일 질문 목록 + 섹션 4개 진입점, 기사가 있는 노선만 활성, 기사 상단 브레드크럼과 크레딧 3줄, 풀쿼트 숫자 하나, 다음 질문 카드 + 관련 질문 2개, 데스크톱 가로 노선 히어로.
- 추가 컴포넌트: 환승 스텝, 비교표, 진행 연표 + 상태 배지(구상·계획·설계·시공).
- 노하우 보호: 홈의 "만드는 방식" 버튼과 소개 페이지의 "제작 방식"·"제작 순서"는 구현하지 않는다. 소개에는 운영 주체·출처 정책(원칙 한 줄 포함)·정정 정책·AI 사용 범위·방문 통계·연락처를 유지한다.

### 카드 모서리 조정 (2026-10-31)

- 사용자 요청으로 기사 카드·홈 표지·채널 안내는 12px(`rounded-xl`), 카드 안 작은 썸네일은 8px(`rounded-lg`)로 조정한다. 노선 목록은 카드 배경이 있는 데스크톱에서 적용한다. 위 기본 radius-0 규칙보다 우선한다.
- 홈 최근 질문은 1px 테두리와 16px 패딩으로 카드 경계를 만든다. 기존 색·서체·키보드 포커스를 유지한다.
- 역명판·숫자 표·하차 칸 표지와 본문 이미지는 기존 모서리 기준을 유지한다.

### 소개 페이지·매거진 방향 조정 (2026-10-31)

- 서울 지하철 역 기사는 현재의 출발 콘텐츠다. 매거진 전체를 서울 지하철로 한정하지 않고, #갈아타다·#걷다·#보다·#바뀌다의 기존 의미를 유지하면서 이동·길·공간·변화를 소개한다. 전국·세계 보도나 발행 일정은 약속하지 않는다.
- 소개 페이지에는 큰 글자·이미지·여백·움직임이 연결되는 스크롤 경험을 허용한다. 이 페이지는 위의 "움직임은 한 번, 한 곳" 제한 대신 장면별 의미와 읽기 흐름을 기준으로 설계한다. 기존 단면 이미지의 단순 확대는 대표 연출로 사용하지 않는다.
- 새 브랜드 일러스트·영상·라이브러리는 전달할 의미가 있을 때 사용할 수 있다. 이후 확정한 실제 사진·교통수단 안내 장면은 아래 기준을 따른다. 사실로 보이는 가상 노선·수치·지도상의 연결은 만들지 않는다.
- 기존 한국어 서체·지하철 안내 체계의 정체성과 정책 앵커를 유지한다. 본문·링크는 정적 HTML로 읽혀야 하며, reduced-motion에서는 이동·확대를 제거하고 내용을 즉시 표시한다. 내부 도구·작성 절차는 공개 페이지에 노출하지 않는다.

### 소개의 실제 사진 장면 (2026-11-01)

- 서울 철길·부산 골목의 일상성을 중심으로 한 실제 사진 방향을 사용자와 확정했다. #갈아타다·#걷다·#보다·#바뀌다는 이동·생활·공간·변화를 읽는 관점이며, 아직 공개하지 않은 섹션은 준비 상태를 밝힌다.
- 사진 캡션에는 장소·장면만 표시한다. 사진가·원문·이용 조건은 내부 콘텐츠 데이터에 보관한다(사용자 결정 2026-11-01). 서로 다른 장소를 하나의 경로로 연결하거나 낮과 저녁을 과거와 현재로 제시하지 않는다.
- 세로 사진은 본래 구도를, DDP 파노라마와 서울로 보조 사진은 전체 비율을 유지한다. 서울로 제공 파일은 1000px이므로 표시 폭을 500px 이하로 제한한다.
- 소개의 장면 전환에는 큰 화면의 본문 고정과 사진 가장자리 마스크, 구분선의 진행을 허용한다. 사진 확대는 사용하지 않는다. 본문과 링크는 처음부터 읽을 수 있고, 모바일·낮은 화면·움직임 줄이기에서는 정적인 순서로 표시한다.
- 도입에는 전철·버스의 측면 일러스트와 공개된 실제 노선도를 둔다. 차량이 실제 지도 위 경로를 달리는 것으로 연출하지 않으며, 이동 수단에서 동네 이야기로 시야를 넓힌다. 추상적인 네 갈래 입체 모형은 사용하지 않는다. 서울로의 낮·저녁 사진은 같은 높이의 한 쌍으로 묶는다.
